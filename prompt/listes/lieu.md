## Incompatibilités

- Type de lieu : Fonds marins ↔ Foule : Foule dense
- Type de lieu : Planète extraterrestre ↔ Architecture : Haussmannienne
- Type de lieu : Désert ↔ Végétation : Mousse
- Type de lieu : Toundra glacée ↔ Végétation : Cerisiers
- Époque : Moyen Âge ↔ Éléments marquants : Hologrammes
- Époque : Moyen Âge ↔ Éléments marquants : Vaisseau dans le ciel
- Époque : Japon féodal ↔ Éléments marquants : Hologrammes
