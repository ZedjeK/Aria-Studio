# Mise en scène

> Proposée pour un sujet Personnage ou Créature (pour un sujet Lieu, le lieu est le sujet lui-même : voir lieu.md).
> **Adulte** : `oui` = lieu masqué quand un personnage mineur est dans la scène (remplace les paliers de relation d'Aria Compagnon).
> Les moments purement narratifs (« le lendemain », « une semaine plus tard ») ont été retirés : ils ne se voient pas sur une image.

## Incompatibilités

- Moment : À midi ↔ Ambiance : Sous les néons
- Moment : À midi ↔ Ambiance : Feux d'artifice
- Moment : Le matin ↔ Ambiance : Feux d'artifice
- Ambiance : Grand soleil ↔ Moment : La nuit
- Ambiance : Grand soleil ↔ Moment : Tard dans la nuit
- Ambiance : Sous la neige ↔ Saison : Été
- Lieu : Un onsen ↔ Saison : Été
- Lieu : Une plage ↔ Ambiance : Sous la neige
- Lieu : Le pont d'un vaisseau spatial ↔ Ambiance : Sous la pluie
- Lieu : Une station spatiale ↔ Ambiance : Sous la pluie
- Lieu : Une station spatiale ↔ Saison : Printemps, cerisiers en fleur
