Aria Studio : composants tiers
=============================

Le code d'Aria Studio est sous licence MIT (fichier LICENSE). Ce fichier liste ce
que le zip embarque et ce qu'Aria télécharge à ta demande, avec la licence de
chaque composant. Relevé le 2026-11-13 sur les versions de requirements.txt et
de catalogue/moteurs.yaml ; à tenir à jour quand l'un des deux change.

Les textes complets des licences des paquets Python sont livrés avec eux, dans
python\Lib\site-packages\<paquet>-<version>.dist-info\licenses\. Celui de CPython
est python\LICENSE.txt.
