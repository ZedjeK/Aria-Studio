                          À SAVOIR
                          
            
                          
            
            
                          
                
                          🖥️ Système moteurs, emplacements, clés d'accès, mises à jour
                          
            
                          
                
                          
                    
                          Moteurs
                          
                    
                
                          
                
                          
                
                            
                
                            Versions épinglées, testées ensemble (catalogue/moteurs.yaml) : téléchargées depuis
                    leur release GitHub officielle, empreinte SHA-256 vérifiée. L'ancienne version reste à côté.
                            
            
                            
            
                            
                
                            Emplacements
                            
                
                            
                
                              
            
                              
            
            
                              
                
                              🔑 Clés d'accès
                              
                
                              Certaines pages Civitai et Hugging Face ne se téléchargent qu'avec ta clé. Elle est rangée
                    dans le Gestionnaire d'identification Windows (chiffré, propre à ton compte), jamais dans un fichier d'Aria,
                    et Aria ne la réaffiche jamais.
                              
                
                                
            
                                
            
                                
                
                                Mises à jour
                                
                
                                
                
                                
                    
                    
                    
                
                                
                
                                
                
                
                                
                
                                
                    
                
                                
            
                                
            
            
                                
                
                                Démarrer avec Windows
                                
                
                                Aria se lance à l'ouverture de ta session, sans ouvrir le navigateur : seule son icône apparaît
                    près de l'horloge. Désactivé tant que tu ne coches pas.
                                
                
                                
                    
                
                                
                
                                
            
                                
            
                                
                
                                Notifications
                                
                
                                À la fin d'une image, d'une retouche, d'un clip, d'une séquence ou d'un casting : une notification
                    Windows (cliquable : elle ouvre l'onglet), avec un son si tu le gardes.
                                
                
                                
                    
                    
                    
                
                                
                
                                
            
                                
            
            
                                
                
                                Fond animé
                                
                
                                Des gouttes allument une grille de points derrière les pages. Le fond se met en pause quand l'onglet
                    est caché, et ses gouttes disparaissent si Windows demande moins d'animations.
                                
                
                                
                    
                        
                        
                        
                    
                
                                
                
                                
            
                                
            
            
                                
                
                                Sauvegardes des réglages
                                
                
                                Avant chaque changement, Aria garde une copie de tes réglages (les 20 dernières).
                    « Restaurer » remet l'une d'elles, après avoir sauvegardé les réglages actuels.
                                
                
                                  
                
                                  Aucune sauvegarde pour l'instant : la première arrive avec le prochain changement.
                                  
            
                                  
            
            
                                  
                
                                  Journal
                                  
                
                                  Ce qu'Aria a fait sur tes affaires : téléchargements, moteurs, corbeilles, migrations et
                    changements de réglages. Les 500 dernières opérations sont gardées dans journal.json ; voici les 50
                    dernières.
                                  
                
                                    
                
                                    Rien encore.
